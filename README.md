---------------------------------------------- App Development ---------------------------------------------------------------------

A structured repository documenting my journey into ''mobile application development'', with a primary focus on ''Dart and Flutter''.
This repository contains my learning progress, practical exercises, and project-based development as I gradually build the skills required to develop modern Flutter applications.


------------------------------------------------- Objective ---------------------------------------------------------------------------

To build a strong foundation in ''Flutter development'' and progressively move toward developing scalable, maintainable, and production-ready mobile applications.
My learning approach combines programming fundamentals, problem-solving, software engineering practices, application architecture, and hands-on project development.



-----------------------------------------------Technology Stack ---------------------------------------------------------------------------

-> ''Language:'' Dart
-> ''Framework:'' Flutter
-> ''State Management:'' GetX
-> ''Backend & Database:'' Firebase
-> ''API Integration:'' REST APIs
-> ''IDE:'' Visual Studio Code
-> ''Version Control:'' Git & GitHub


----------------------------------------------- Skills & Concepts ---------------------------------------------------------------------------

My Dart foundation includes ''object-oriented programming, classes, objects, constructors, collections, null safety, functions, and asynchronous programming'', with an emphasis on understanding programming logic and problem-solving.

With Flutter, I have worked with ''widgets, layouts, responsive UI, reusable components, forms, dialogs, navigation, drawers, bottom navigation, and user interactions'' while learning how Flutter applications are structured.

I have also learned ''GetX state management'', including reactive variables with `Rx`, `Obx`, dependency injection with `Get.put()` and `Get.find()`, GetX controllers, named routes, `GetPage`, and navigation.

----------------------------------------------- Architecture ---------------------------------------------------------------------------

I have practiced ''MVC architecture with GetX'' by separating application responsibilities into Models, Views, Controllers, Services, and Routes.

This helped me understand how application logic can be separated from the UI and how a Flutter project can be organized for better maintainability and scalability.

----------------------------------------------- Backend Integration ---------------------------------------------------------------------------

My Flutter learning has progressed beyond frontend development into backend integration.

I have worked with ''Firebase Authentication and Cloud Firestore'', including user registration, login, logout, authentication flows, and basic Firestore CRUD operations.

I have also started working with ''REST APIs'', learning how Flutter applications communicate with external services through HTTP requests, JSON data, models, services, controllers, and reactive UI.

----------------------------------------------- Projects ---------------------------------------------------------------------------

The projects in this repository represent different stages of my Flutter development journey.

Each project is built to apply the concepts I have learned rather than simply following tutorials, with increasing focus on ''clean structure, state management, architecture, backend integration, and real application workflows''.
